# 개발 계획 — 현장별 공정·기성 대시보드

## 한눈에 보기

- EPIC 3개, Story 12개로 나눠 EPIC ① 자료 가져오기·필터·현황·추이 → ② 점검 현장·기록 펼침·CSV → ③ 근거를 보여주는 AI 질의 순서로 만듭니다.
- 각 Story마다 브라우저에서 해 볼 행동과 화면에 보여야 할 결과를 적었습니다(터미널·코드·개발자 도구는 보지 않습니다).
- EPIC마다 자동 검사(Vitest)를 돌리고, 사용자가 "확인했어요"라고 답한 Story만 완료로 표시합니다.
- 전체 구현과 로컬 검증이 끝나면 결과를 보고하고 멈춥니다.
- GitHub 저장과 Vercel 배포는 Story가 아니며, 각각 사용자가 별도로 요청한 뒤에만 진행합니다.

진행 상태 표시: `구현·자동 검사 완료`는 만들었고 자동 검사가 통과했다는 뜻이며 완료가 아닙니다. `완료`는 사용자가 화면에서 확인했다고 답한 뒤에만 적습니다. 결과는 `docs/05_테스트결과.md`에 기록합니다.

앱은 `http://localhost:3000`에서 열립니다(3000번이 사용 중이면 다른 번호를 안내합니다).

### EPIC 3 — 근거를 보여주는 AI 질의

시작 전에 강사에게 받은 Gemini API 키를 직접 `.env.local`에 넣습니다. 키 값은 대화에 붙여 넣지 않습니다. 실제 AI 확인은 이 키로 하고, 키가 없을 때는 "모의 응답" 표시가 붙은 확인으로만 진행합니다.

| 번호 | 사용자가 할 수 있는 일 | 확인할 행동 | 보여야 할 결과 | 상태 |
|---|---|---|---|---|
| 3-1 | AI 화면에서 범위를 확인하고 질문해 답을 받는다 | "AI 현장 진단" 메뉴를 열어 예시 질문 "D가 늦어진 원인과 대응은?"을 누르고 "전송"합니다. | 왼쪽에 기준월 2026-09·대상 12개 현장·전체 기성률 67.2%·공정차이 -2.0pp·점검 현장 칩(D·I·K)과 예시 질문 4개가 보입니다. 예시를 누르면 입력창에 채워지고, 전송하면 "AI 답변을 기다리는 중" 뒤에 답변이 나옵니다. 답변 아래에 "기준 2026-09 / 현장 D · 근거 숫자: 계획 86.5% · 실제 75.8% · 공정차이 -10.7pp · 기성률 69.4%"가 보이고, 내용은 기록된 상황(공급 정상화 후에도 남은 지연)과 기록된 대응 계획(주간 확인)을 기록대로 설명하며 "완료나 원인 확정이 아닙니다" 문구가 붙습니다. | 구현·자동 검사 완료 (실제 AI 호출 확인) |
| 3-2 | 근거가 있는 질문은 근거와 함께, 자료에 없는 질문은 "알 수 없다"로 받는다 | "점검 현장은 어디인가요?", "실제 준공일과 미수금 현황은?"을 차례로 묻습니다. 현장 "D"를 고르고 "D는 회복 중인가요?"를 묻습니다. 현장 "J"·월 "2026-07"로 바꿔 "7월 기성이 왜 늘지 않았나?"도 묻습니다. | 점검 질문에는 D(-10.7) → I(-7.6) → K(-5.4)와 기준 월·현장이 붙습니다. 회복 질문에는 8월 -11.2pp → 9월 -10.7pp로 0.5pp 줄었고 점검 상태는 유지라고 월별 요약을 근거로 답합니다. 준공일·미수금 질문에는 "자료 없음"과 함께 계약상 준공일은 예정일이며 실제 완료일과 다르다고 답합니다. J 7월 질문에는 기성 확인 서류 보완이라는 기록을 근거로 설명합니다. 답변마다 참고한 기록 필드(기록된 상황 등)가 표시됩니다. | 구현·자동 검사 완료 (실제 AI 호출 확인) |
| 3-3 | 범위를 바꾸면 이전 답변이 지워지고, AI가 실패해도 나머지는 계속 쓴다 | 답변이 있는 상태에서 월이나 현장을 바꿉니다. 질문을 보낸 직후 기다리는 중에 월을 바꿉니다. 제가 임시로 켜는 "AI 연결 실패" 확인 모드에서 질문한 뒤 현황 요약과 CSV 내보내기를 눌러 봅니다. | 필터를 바꾸면 이전 답변이 사라집니다. 기다리는 중에 바꿔도 늦게 온 답이 새 범위에 나타나지 않습니다. 실패 때는 "AI 연결 실패: 이유 한 줄. 대시보드와 CSV는 계속 쓸 수 있습니다"와 "다시 시도"가 보이고, 현황·비교표·CSV는 그대로 동작합니다. (이 확인은 모의 오류이며 실제 한도 초과·키 오류를 겪은 것은 아닙니다.) | 구현·자동 검사 완료 (모의 오류로 확인) |
